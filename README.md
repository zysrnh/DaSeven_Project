# DaSeven_Project

### Anomali SMK: Cosmic Card RPG
Game 2D Pixel Art Turn-Based Action RPG bertema anak SMK melawan anomali alien abstrak di koridor sekolah.

## Fitur Utama
- **Overworld Eksplorasi (ala Pokémon)**: Grid map 2D retro dengan pergerakan 4 arah karakter anak SMK (seragam putih abu-abu, tas ransel) di Koridor & Lab Komputer SMK.
- **Sistem Pertarungan Turn-Based Card**: Mekanik kartu aksi khas anak teknik (Penggaris Besi 30cm, Pecutan Kabel LAN, Hantaman Kunci Pas, Buku Modul Tebal, Es Teh Kantin, Tespen Volt Surge).
- **Active Action Timing (QTE)**: Mekanik timing sweet spot (Spacebar) saat menyerang untuk memicu Critical Hit x2.0.
- **Enemy Parry Reaction**: Fitur tangkisan bertahan saat alien menyerang untuk meredam damage hingga 80%.
- **Audio Sintetis**: Sound effects retro via Web Audio API tanpa perlu file audio eksternal.
- **Visual Retro 32x32 Pixel Art**: Sprite procedural 32x32 pixel dengan rendering pixelated.

## Cara Menjalankan
```bash
npm install
npm run dev
```
Buka browser di `http://localhost:5173`.
